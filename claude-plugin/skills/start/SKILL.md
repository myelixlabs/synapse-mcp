# Start Synapse

1. Run `synapse-mcp start` in the shell.
2. If the command is not found, Synapse is not installed: suggest `/synapse-mcp:setup` and stop.
3. Run `synapse-mcp status` and report whether the server is now running.
4. If the Synapse tools do not appear in this session, ask the user to reconnect the server from `/mcp`.
